Frequently asked questions

How do I create a project?

Open My Projects and use the New Project action. In this starter UI, the button is a demo control; connect it to a project form and database to save projects.

How can I assign a task to a teammate?

Open My Tasks, choose Add Task, select a workspace and assignee, set the due date and save. Task assignment is a planned backend feature in this sample.

What is a handover?

A handover is a transfer of work or files to another teammate. Include context, current status, open questions and next steps.

Where can I find shared files?

Open Library to browse documents, folders, templates and reference collections shared with your workspaces.

How do I change notification settings?

Open Settings, choose Notifications and switch the updates you want to receive. Saving preferences requires backend persistence.
